# 有效产品与工程决策

2026-10-25 后续决定：正式 126.6 秒超时证明不能依赖首次运行期编译成功后才生成缓存。采用构建期准备并严格验证随包前端产物，首次 managed 启动即可复用；仅无 Git 的固定发行后端跳过 Git 版本查询。保留全部数据初始化和原生失败回退，不通过无限延长截止或关闭防护解决问题。本轮隔离 Electron 测试触发 0x80000003，停止此类自动复现，后续仅 Node/headless Edge 验收；正常正式启动与原生异常仍未验收。详见[后续证据](verification/2026-10-25-startup-followup.md)。

2026-10-25 启动性能决定：用户授权无人值守审核和修复；保留原生业务、数据检查、回环/CSRF/进程归属保护，通过固定版本的内存适配复用校验后的编译产物，不直接改写上游核心。缓存局限在 managed 配置的既有缓存目录，未知版本或任何失效均回到原生启动。性能结论区分隔离 warm-profile 与正式 114 秒记录，不以约两秒的隔离结果代替正式实例验收。见 [启动性能报告](verification/2026-10-25-startup.md)。

2026-10-25 新决定：用户确认彻底替换旧 UI，并允许重做外观与主题接口。统一以 `sillytavern_ui_demo.html` 为视觉依据；保留原生业务能力、数据格式与设置，不要求旧主题 CSS 直接适配新布局。旧主题/自定义 CSS 原配置保留，原 CSS 默认不控制桌面布局，可从新主题界面显式开启兼容。复杂功能以新设置中心、统一组件和原节点适配呈现；不以回到旧工具栏作为日常操作的完成路径。实现和验证范围见 [UI_REBUILD.md](UI_REBUILD.md)。

2026-10-23 新决定：用户明确同意并要求执行以 `sillytavern_ui_demo.html` 为视觉基准的统一现代化，取代 D06 中“不引入整套主题”的旧视觉限制。实现采用原型色值、材质和布局，不引入其生产 CDN；继续保留原生数据和事件、模式参数隔离、显式采用与本地文件权限边界。原型示例余额/用量/张力没有真实来源时不展示伪造数字。当前实现和验收见 [2026-10-23 记录](verification/2026-10-23-modern-ui.md)，原表保留原始决策背景。
