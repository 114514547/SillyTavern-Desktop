## 当前缺陷与风险

1. **RP 切换旧面板浮到中央（交接时缺陷；10月22日源码已修）**：用户 `QQ20261021-221132.mp4` 约 1～2、14～15、20～21 秒，右侧新页已开，旧格式/背景/扩展/世界书页短暂在聊天中央展开再消失。代码初步线索为 `releaseDock/closeNative` 先移除停靠 CSS，而上游 display 关闭过渡仍生效；当时尚未通过完整页面复现确认；10月22日已在完整隔离页面确认离场过渡机制并修复，见最新修复记录。不能写成“永久无法关闭”。
2. **原生复杂控件被挤坏（交接时缺陷；10月22日源码已适配）**：250px 默认栏宽仍沿用多列，高级格式标题/模板接近竖排，用户设置和身份页难读。背景页约 18 秒出现横向滚动条和按钮挤压。需要逐页响应式排布，不能只以“可拖宽”代替默认可用性。
3. **旧测试夹具覆盖不足（已新增完整原生回归；旧夹具仅作补充）**：smoke-roleplay-navigation.cjs 禁用动画并简化完整控件；16 项 Edge 隔离检查通过并未捕获前两项。应保留历史证据，同时增加正常动画/完整原生内容验证，不能把设计稿或占位 DOM 当实际安装版验收。
4. **Electron 原生异常（用户截图，未确认原因）**：Windows 曾报告 electron.exe PID 35436 未处理 win32 异常。没有可靠故障模块/堆栈/可重复根因，不能断言与布局、显卡或某插件有关。后续必要时只读查询对应事件，避免反复启动干扰电脑；本次未启动 Electron。
5. **偶发启动慢（未解决）**：已有阶段计时和启动页提前显示。历史 0.5 warm-profile 可用耗时约 6.5～6.6 秒，不代表冷启动，也不能证明用户的长时间卡顿已消失。继续以不含内容的阶段记录定位。
6. **布局持久化可能受端口影响（待验证）**：RP 布局只用 localStorage，后端用随机端口。源代码显示这两个事实；跨真实重启/不同 origin 的恢复未验证。现有同页持久化测试不足以证明重启恢复。
7. **源码、包、正式安装不同步（已核对）**：D 盘产品 0.4.0；dist/0.5.0 为旧 0.5.0 快照；最新 Agent/RP UI 改动在当前工作树，版本字段尚未再次递增。不能用旧 ASAR 的一致性结论覆盖今天的源码。
8. **大量成果未提交（已核对）**：审查起点有 21 个已跟踪文件修改、42 个 desktop/scripts/tests 新文件；写作扩展和 Agent 等关键源码仍是 untracked。HEAD/远端已有提交不是完整备份，新会话必须保留工作树。迁移只 clone 会丢失这些成果。
