## 实施约定

- 展示样式分为共享设计变量/组件、页面布局、原生兼容三层；旧覆盖规则原位替换，不追加同类补丁。
- 复杂原生编辑器保留原节点、ID 和事件依赖的父链；重新组织导航、尺寸、表单和材质，不复制隐藏控件或创造另一份业务状态。
- 原生抽屉作为功能载体接入现代设置，不以暴露旧工具栏或跳回旧布局作为正常完成路径。
- 新主题只接受版本化、受约束的设计变量。原主题配置不删除；依赖旧选择器的 CSS 不自动迁移。
- 不把静态原型中的人物、心率、张力、余额等展示为产品真实数据。
- 测试使用新隔离资料、完整原生前端和隐藏 Edge；禁止真实模型请求、默认 Electron 或正式资料。

## 状态

本轮源码改造及隔离验证已完成。没有修改上游业务实现、生成/传输、小说数据模型与存储、Agent 工具权限及正式用户资料。复杂管理功能保留原控件与内部事件结构，通过宽设置中心、导航、查找和新的控件样式适配，未声称将这些业务编辑器重新实现。

## 已落地

- 替换原 `style.css`/`modern-ui.css` 中重复的视觉与布局规则。文档样式中的 `!important` 从 586 处收敛为 60 处，主要用于原生固定位置、内联尺寸、隐藏状态与系统减少动效；Shadow 样式单独维护，不影响文档节点。
- 原 RP 抽屉停靠队列、位置测量和重复观察器退役；常用参数留在右栏，复杂功能与程序化抽屉请求进入统一宽面板。顶部重复设置入口删除。
- 原生九类完整设置加入字段查找与分区跳转，保持原节点、ID、字段父链和 Select2 生命周期；设置中心的 tab 选择器限定在自身导航，避免改写原生编辑器内的 tabs。
- 重做小说画布、栏内工具条、讨论输入区和可调整参考区；移除硬编码人物、心率、张力与五感数据。参考区显示真实章节大纲或作品要求。
- Agent 合并为单一样式文件，继承共享主题；修复窄屏返回后的侧栏恢复、专注模式还原和 Shift+F10 与 F10 的冲突。
- 新主题支持受约束的 JSON 导入导出、配色、字体、字号、密度、圆角、模糊与动效。原自定义 CSS 默认暂停，可显式开启兼容，内容和配置不删除。主题/布局通过酒馆用户配置保存，支持旧 localStorage 的只读迁移。
- 分发白名单登记全部新模块；退役的 `modern-agent.css` 通过原有备份与原子安装机制更新。新代码拒绝未知额外文件，不直接覆盖正式运行副本。
