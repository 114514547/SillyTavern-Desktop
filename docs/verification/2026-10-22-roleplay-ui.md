# RP 三栏局部修复与验证（2026-10-22）

本次沿用实际未提交工作树，只修改 `desktop/extensions/desktop-writing/roleplay-ui.mjs`、`style.css`，新增 `scripts/smoke-roleplay-native.cjs` 并补充本记录及交接状态。没有修改原生聊天/设置面板父级、上游核心、模型连接、聊天保存、小说或 Agent 业务逻辑，没有迁移、打包或覆盖安装。

## 复现与修复

读取既有录屏抽帧并在完整固定版本原生前端中复现。修复前逐帧捕捉到原生抽屉已为 `closedDrawer`，仍在原浮动位置保留可见高度。上游 `.drawer-content` 对 `height, display` 使用 `allow-discrete` 离场过渡；此前移除停靠后恢复该过渡和原生坐标，使已关闭面板继续绘制。这一机制在隔离完整页面中得到验证；没有据此推断 Electron 异常等其他问题的根因。

退场现在同步结束该面板的过渡并提交关闭状态，再恢复原行内过渡声明及 pin 状态，避免回到聊天中央绘制。仅退场抽屉受此瞬时处理，原生其他动画、控件和事件保留。另在窗口 resize 事件中及时测量停靠区域，消除窗口尺寸改变时一帧沿用旧坐标的现象。

右栏以自身宽度作为容器查询条件，480px 及以下将高级格式、界面和身份的主要列改为单列；标题、预设、工具按钮、分页与输入控件可以换行，保留原生展开编辑入口。背景页恢复原生 flex 滚动结构，按钮组回到正常文档流，页签和操作按钮分行；缩略图栅格随栏宽和原生缩放设置调整。没有使用隐藏横向溢出来裁掉按钮。800px 及以下保留原有侧栏覆盖模式，纠正绝对定位仍被零宽 grid-area 限制的问题，并把侧栏置于顶部控制区下方，避免遮住收起按钮。

## 验证与边界

最终通过：完整原生 UI 15 组检查、60 次页面测量、2209 个动画帧，面板越界 0、横向溢出 0、页面错误 0；74 文件语法检查、4 项 RP 单元测试及16项既有导航检查通过。

`node scripts/smoke-roleplay-native.cjs` 使用 `test-results/rp-native-20261022` 下本轮新建的独立 managed 配置及真实固定后端，运行 headless Edge。调试轮次复用该专用合成配置，没有读取正式设置、聊天、故事或模型密钥；没有启动 Electron，没有调用模型接口。页面请求仅放行该本机后端，模型生成和外部浏览器请求均被拒绝。

通过原生“禁用模糊效果”开关启用正常原生动画，记录原生非停靠抽屉的非零过渡时长；九个设置页加载完整原生内容，测试没有替换为占位控件或关闭全局动画。覆盖连续/快速切换、收起和重开、250/320/480/640px 栏宽、1400/1024/800/390px 窗口、小说/Agent 来回切换、原生回退、模板展开编辑、背景缩略图缩放、行内过渡声明保留及原生 DOM/未提交文本保持。逐动画帧检查抽屉没有离开右栏；逐页测量横向滚动宽度，并检查窄栏标题和主要列的可读宽度。

本机完整报告与合成截图位于 `test-results/rp-native-20261022/after/`，修复前诊断位于 `before/`；这些被忽略且不随源码提交。另运行 RP 相关单元检查、语法检查及旧导航回归。旧简化夹具只用于补充检查导航回归，不能替代此次完整原生页面结果。

本次证明的是 headless Edge 下固定原生前端与独立真实后端的上述场景。未启动 Electron，未验收正式用户配置、真实模型或所有社区插件；Electron 原生异常、偶发冷启动慢和跨随机端口的布局持久化没有纳入修复。

## 人工验收入口

先正常退出当前酒馆及安装版，再使用既有“SillyTavern 源码开发版”快捷方式完整重启（不能只 Ctrl+R）。在默认栏宽连续切换格式、参数、背景、扩展、世界书和身份，确认旧页不在聊天中央出现；检查格式/界面/身份的标题、模板和输入框，并打开原生展开编辑；在背景页检查全局/聊天页签、上传/文件夹/缩放按钮及纵向滚动。随后收起重开、调整栏宽及窗口宽度，切换小说/Agent 后返回，最后检查“原生”与“返回三栏”。不用发送模型请求即可完成这些验收。
