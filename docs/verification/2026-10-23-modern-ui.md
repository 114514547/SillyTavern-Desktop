# 2026-10-23 原型 UI 落地与验证

本轮用户授权以仓库 `sillytavern_ui_demo.html` 为视觉基准，实施三模式和统一设置的现代化。原型保持原样；修改落在 desktop 扩展源码，没有修改固定上游、安装产品、正式用户数据、依赖版本或发布产物。开始时当前工作树已有 Gemini 加入的 SVG、输入底栏、右键菜单和初版 SettingsDialog，本轮在这些成果上完善并集成，没有重置工作树。

## 当前实现

共享 `design-system.css` 统一文档与 Agent Shadow DOM 的黑金色值、字体、组件样式；`modern-ui.css` 和 `modern-agent.css` 实现原型中的玻璃渐变、边缘高光、圆角、消息区、输入坞和分栏材质。新增 `icons.mjs` 为应用操作提供固定 SVG，新增资源均进入 `writing-extension.cjs` 分发白名单。生产界面不依赖 Tailwind CDN，也没有增加 UI 框架。

Agent 底栏改为中心列自适应的单行优先布局，写入权限移到引用提示行；窄中心列有明确的两行退化。文档区支持 Markdown 只读预览、上下拖动、全高与折叠，编辑/对照/备份路径保留。预设窗口使用 Shadow 内真正的模态 dialog。右键菜单保留与原型一致的网页外观，补齐 Shift+F10、方向键、Escape、焦点还原；非当前讨论重命名通过其自身版本保存，项目右键新建讨论等待切换完成并选择新记录。删除继续检查生成、文档未保存、摘要草稿和保存队列，并展示级联影响。

RP 保留原生 chat/form 及其直接父级。左侧角色行加入头像，聊天气泡与发送器使用同一材质；默认参数页显示由真实原生控件驱动的紧凑温度、输出和上下文控制。完整参数、九类功能和原生回退仍可进入。整体折叠会释放真正的外部停靠面板，边缘唤回改为可键盘操作的按钮。

小说继续三栏和显式采用/快照保护，正文采用原型画布材质，剧情推演卡移到正文下方，右侧提供可调高度的真实大纲/参考区。已有剧情分支模板被明确标为推演方法，没有将模板声称为模型生成结果；章节标题和正文片段以文本节点呈现。原型中的余额、缓存比例和张力数值没有填成虚构的产品数据。

统一设置由 `SettingsDialog` 管理，提供连接/用量、模型 API、生成参数、Agent 配置及全部原生功能分类。常用字段通过真实原生 input/change 事件写入；密钥使用正确提供商 SECRET_KEYS，空输入保持原样，失败不会显示保存成功。参数提交额外读回对应服务端字段确认。移除了初版前端直接访问远程 /models、将 401/403/404 判为成功并重写 onlineStatus 的逻辑。

复杂原生页临时将整个 top-settings-holder 子树置于 modal top layer，保留面板内部父链、节点和事件；退出时恢复外部位置、class/pin 状态和未保存内容。Select2 下拉在此期间使用模态层作为挂载父级，退出后恢复。RP 停靠与中央面板通过暂停/恢复协调，避免同时持有原生内容。

现代界面检查包含七类复杂原生内容页、原生嵌套编辑弹窗、模型/密钥字段实际保存、空密钥与 HTTP 失败反馈、参数保存读回、节点身份/父级/未保存文本恢复、命令罗盘、Shadow SVG 和右键键盘操作、生成/编辑中的删除拦截、预设模态框、文档预览和三模式在 1600/1280/1050/800px 下的布局及顶栏入口可达性。原生回归继续使用完整上游内容和正常动画，覆盖连续切页、250/320/480/640px 栏宽、390px 等窄屏、背景缩放、切模式与回退。

两次已暴露问题被修复后才通过：初轮默认栏宽变化使旧布局默认值断言不符，已按新默认值更新预期；完整 RP 检查中主题页标题的固有宽度不足 80px，已补充最小可读宽度。原生回归助手也修正了“已打开目标页却再点一次将其收起”的前置状态处理，并支持指定独立测试 home，未降低原有验收条件。

所有浏览器验证使用隔离合成文件夹、作品、讨论与测试凭据，模型生成请求被阻止，模型状态查询使用本机模拟响应，没有调用真实收费模型，也没有启动 Electron。测试使用真实 LocalWorkspace 方法对删除持久化失败做纯内存故障注入，确认当前服务实现能回滚；该回滚在本轮开始前已存在，本轮未重复改写后端删除服务。

## 运行与实际边界

正常退出当前源码版后，通过仓库 `启动源码开发版.lnk` 或 `npm run dev` 完整重启，启动流程会同步白名单内新增模块与样式。Ctrl+R 只刷新已安装到目标后端的前端副本，不能替代这次完整重启。默认数据与其他安装共享时，继续避免两个产品同时写同一数据根。

本轮验收证明当前隔离页面的功能和几何约束，不等于正式 Electron 窗口、全部社区插件/自定义 CSS、真实提供商或逐像素完全一致的验收。采用了原型的视觉基准，同时保留原型未覆盖的原生完整功能；真实余额、模型特定能力与个别复杂扩展内容仍由其实际接口决定。没有打包、安装、提交、推送或发布。
